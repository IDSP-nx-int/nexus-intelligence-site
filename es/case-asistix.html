ASISTIX — Analítica y automatización de asistencia

Caso real de automatización y analítica para control de asistencia, solicitudes de justificante, aprobaciones, evidencias y dashboards para RH y dirección usando herramientas Microsoft 365.

Contacto
Microsoft Forms Power Automate SharePoint Excel Online Power BI

Datos rápidos

  • Contexto: solución interna para organización pública
  • Usuarios aproximados: 100
  • Solicitudes mensuales: 450 aprox.
  • Área usuaria: RH / Dirección / Jefaturas
  • Enfoque: trazabilidad, reporteo y control operativo

1) Contexto / problema

El control de asistencias y justificantes estaba distribuido entre correos, archivos, registros manuales y consultas operativas. Esto generaba riesgo de pérdida de información, criterios inconsistentes, poca trazabilidad y dificultad para consolidar reportes para RH y dirección.

2) Solución

Entregables principales

  • Captura centralizada de solicitudes mediante Microsoft Forms.
  • Flujos de aprobación con Power Automate, Outlook y reglas por tipo de solicitud.
  • Evidencia documental almacenada y vinculada mediante SharePoint.
  • Bitácoras estructuradas en Excel Online como fuente operativa para consulta y reporteo.
  • Dashboards Power BI para seguimiento de ausencias, retardos, justificantes e incidencias.

Flujo operativo

  • Empleado envía solicitud con datos requeridos.
  • Power Automate aplica validaciones y envía aprobación.
  • Jefatura aprueba o rechaza.
  • Se notifica resultado y se registra en bitácora.
  • Power BI consume la información para reporteo operativo y ejecutivo.

La solución ayudó a convertir un proceso manual en un flujo más estructurado, trazable y medible.

3) Modelo analítico y arquitectura

Modelo de datos

  • Calendario laboral empleado-día como base analítica central.
  • Registros biométricos como fuente de eventos de entrada/salida.
  • Catálogos de empleados, horarios, días inhábiles y tipos de justificante.
  • Bitácoras de justificantes provenientes de formularios y registros operativos.

Automatización y reporteo

  • Power Automate para validaciones, aprobaciones, notificaciones y registro de resultados.
  • SharePoint para evidencia y archivos relacionados.
  • Excel Online como bitácora operativa y fuente estructurada.
  • Power BI para modelos, medidas DAX, dashboards y análisis mensual.

4) Funciones clave

  • Clasificación de incidencias: normal, retardo, falta, justificado o pendiente.
  • Ventanas de solicitud: control de periodos permitidos y reglas por tipo de justificante.
  • Trazabilidad: solicitante, aprobador, fecha, resultado, evidencia y estatus.
  • Reporteo operativo: seguimiento por empleado, área, mes, tipo de incidencia y estatus.
  • Modelo empleado-día: permite analizar qué debía ocurrir y qué ocurrió realmente.

5) Métricas y alcance

Escala aproximada

  • Usuarios: 100 aprox.
  • Solicitudes mensuales: 450 aprox.
  • Fuentes: Forms, Excel Online, SharePoint, SQL/MySQL, sistema biométrico.
  • Reportes: seguimiento operativo y ejecutivo en Power BI.

Indicadores trabajados

  • Ausencias y retardos.
  • Justificantes aprobados, rechazados o pendientes.
  • Incidencias por área, empleado y periodo.
  • Empleados con incidencias recurrentes.
  • Seguimiento mensual para RH y dirección.

Capturas representativas del flujo de captura, aprobación, evidencia y reporteo.

7) Mejoras futuras

  • Migrar bitácoras operativas desde Excel Online hacia Dataverse para mayor gobernanza.
  • Agregar recordatorios automáticos y escalamiento de aprobaciones pendientes.
  • Formalizar ambientes Dev/Test/Prod para empaquetado y despliegue controlado.
  • Ampliar dashboards con métricas de tendencia, recurrencia y tiempos de respuesta.
