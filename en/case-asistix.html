ASISTIX — Attendance & Justification Management

A production-grade Microsoft 365 solution to standardize justification requests, enforce rules, orchestrate approvals, centralize evidence, and deliver audit-ready reporting for HR and leadership.

1) Context / Problem

Attendance and justification control was fragmented across informal channels (emails/chats), loose files and spreadsheets, resulting in payroll risk, audit gaps, and inconsistent criteria across managers.

2) Solution (what I delivered)

Core deliverables

  • Centralized intake via Microsoft Forms with branching by request type.
  • Rules + approvals in Power Automate (validation, routing, notifications, outcomes).
  • Evidence-first traceability with controlled storage + link per request.
  • Single source of truth logs for auditing (request + approver + timestamps + evidence link).
  • Reporting portal with Power BI dashboards embedded in SharePoint.

Request flow

  • Employee submits request → validations applied → approval request sent
  • Manager approves/rejects → employee + HR notified (as applicable)
  • Log updated (bitácora) + evidence linked → dashboards update on refresh cadence

This design standardizes criteria and produces audit-ready artifacts by default.

3) Architecture

Data

  • Time-clock events as a fact source (SQL or clock system export).
  • Employee-day calendar (one row per employee/day) to reconstruct final status.
  • Catalogs (employees, schedules, types, holidays, special activities).
  • Justification logs (approved / physical / external) with consistent fields.

Automation + Evidence + Reporting

  • Power Automate: validations, approval orchestration, notifications, run-after hardening.
  • SharePoint / Excel Online: controlled logs + parameter tables + evidence links.
  • Power BI: semantic model + operational/executive dashboards embedded in SharePoint.

4) Key Features

  • Retroactive window enforcement (policy-driven: “only last N business days”).
  • Daily status reconstruction (Normal / Late / Absent / Justified) with full audit context.
  • Payroll-ready outputs (clean records for export/upload within a configurable date range).
  • Evidence-first auditability: each case retains approver, timestamps, evidence link, and origin.
  • Role-aware portal behavior: employee vs manager team view vs HR/leadership consolidated view.
